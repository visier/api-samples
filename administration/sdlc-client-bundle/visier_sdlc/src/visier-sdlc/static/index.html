PROMOTION GUIDE

A clear path to production

Keep your tenants aligned, one considered release at a time.

  1. Review your development changes

    Select the newest version you want to promote. All earlier unsynced versions are included automatically.

  2. Resolve production drift

    If changes were made directly in production, roll back to the saved baseline. Use Reset sync baseline if the issue was resolved outside this tool, or the production changes are known not to cause merge conflicts with pending development changes.

  3. Sync with confidence

    The app exports a ZIP, creates a production draft, imports the changes, and commits and publishes it.

  4. Check the result

    Both lists refresh automatically. A successful sync becomes the new baseline and rollback point.
